# Task: replace this machine's bar and apps with a Quickshell shell

## Goal

Turn this dotfiles setup from "ashell bar + a pile of small scripts and rofi
menus" into a **Quickshell-driven desktop shell**, modelled on
<https://github.com/na-ive/nandoroid-shell> (an opinionated Quickshell-based
Hyprland shell inspired by Android custom ROMs).

Use that repo as the **design and architecture reference**. Do not install it,
and do not copy it wholesale — see "What to borrow and what not to" below.

**Do not remove any application the user already has.** You are adding a shell
alongside them and switching the bar over once the replacement works. Deleting
ashell is the *last* step and only after the new bar is verified.

## The machine — verified, do not re-check

- Arch, Hyprland 0.56.2, session started by SDDM, `niri` also registered
- Intel HD 520, **4 cores, 8 GB RAM**. This is the single most important
  constraint. No heavy compositing, no shader stacks, no big image grids.
- **`quickshell` 0.3.1 is already installed.** Nothing to install.
- **11 standalone quickshell configs already exist** in `~/.config/quickshell/`:
  `hub` (66 qml), `keys`, `keys-hint`, `plugins`, `reload-cover`, `ryopin`,
  `ryoshot`, `ryostore`, `ryovm`, `shell` (488 qml, 8.2M), `welcome`.
  **Read these first.** They are this machine's own Quickshell work, they are the
  house style, and some of them already solve problems you would otherwise
  re-invent.
- Qt 6.11.2, `QtQuick.Controls` available, `QtQuick.Effects` available.
- Wallpaper daemon `awww` + an `awww` shim at `~/.local/bin/awww` that adds the
  expanding-circle transition. Always call `awww`, never `/usr/bin/awww`.
- Notification daemon is **ashell**, which took the `org.freedesktop.Notifications`
  bus name from mako when mako was removed from autostart. `mako` is still
  installed but must not be started — one bus name, two claimants loses.

## API facts, measured. Do not re-derive these, they are the whole design.

**Quickshell 0.3.1 quirks that will bite you.** All four cost me real time:

| thing | what actually happens |
|---|---|
| `new Foo {}` | parse error `Expected token ';'`. Use `new Foo()`. |
| `Quickshell.quit()` | **not a function** in 0.3.1. Use `Qt.quit()`. |
| `Process.exitCode` | reads `undefined` on `onStreamFinished` *and after exit*. Only `onExited` carries a real status. Deciding success on `exitCode` silently discards every good reply. |
| `Region` | has `item`, **not** `region`. |
| `PanelWindow.width/height` | deprecated; use `implicitWidth`/`implicitHeight`. |
| `ComboBox` delegate | declaring `required property var modelData` makes `index` a context property that stops resolving — add `required property int index` too. |
| `XMLHttpRequest` | **silently drops a `Cookie` header.** Verified against a local echo server: `X-Probe` arrived, `Cookie` did not, and `setRequestHeader` reported success. Shell out to curl for anything authenticated. |

**`Quickshell:Services` is the port surface.** Verified present in 0.3.1:

```
Quickshell:Services/Mpris           -- playerctl replacement
Quickshell:Services/SystemTray     -- ashell's Tray
Quickshell:Services/Notifications  -- can own org.freedesktop.Notifications
Quickshell:Services/UPower          -- ashell's battery
Quickshell:Services/Pam             -- lock/logout
Quickshell:Services/Pipewire        -- ashell's audio
Quickshell:Services/Polkit
```

Read the `.qmltypes` in `/usr/lib/qt6/qml/Quickshell/Services/<Name>/` for the
exact property names instead of guessing them from the Wayland/Qt equivalents.

**There is no waybar-style `--reload`.** ashell has no hot-reload either — a
theme switch has to `pkill -x ashell` and respawn it. Quickshell configs are
separately launched processes (`quickshell -c <name>`), so a "restart the bar"
means killing one named config and starting it again. Say so plainly in the code
rather than pretending a reload exists.

## What to borrow from nandoroid-shell, and what not to

Borrow: the **architecture** — a `Singletons/` directory of services
(`Colors`, `Config`, `Hyprland`, `Notifications`, `Audio`…), one named config
per surface (`bar`, `launcher`, `notifications`, `settings`), a
`Singleton`-registered `qmldir` per directory, panel components separated from
service components.

Do **not** borrow:

- **Its 398 QML files.** That is a full desktop shell. This is a 4-core machine
  with one bar and a handful of panels. Target something in the tens of files.
- **Its wallpaper set** (29 files), **weather** (66 svg files), **lock** setup
  (33 files) — hyprlock config, not applicable.
- **Its `install.sh`.** Never run it here. It would overwrite this repo's setup.

It is **AGPL-3.0**. Read it for ideas; if you copy code rather than patterns,
the licence obligation is the user's to meet, so **prefer reimplementation and
say so in the commit message** if you take anything verbatim.

## Repo conventions — follow exactly

- Repo: `/home/water/Dotfiles-mine` (git, branch `main`)
- `~/.config/<app>` are **symlinks** into `config/<app>` — edit the repo file.
- **`~/.local/bin/*` are copies, not symlinks.** A new or edited script in
  `local/bin/` does NOT reach `~/.local/bin/` until `install.sh` runs. After
  adding one, copy it and verify with `cmp`. This has broken things here before.
- **`local/bin/theme-apply` owns all theme colours** and re-renders them into
  every app's config, including `[appearance]` in `config/ashell/config.toml`.
  When you add a Quickshell shell you must **extend `theme-apply` to render its
  colours too** — a shell with hardcoded greys will drift from the desktop within
  one theme switch. Look at `render_ashell_palette` / `patch_ashell_palette` for
  the pattern.
- **Never modify `home/.bashrc` or `home/.bash_profile`** — the user has
  uncommitted edits there.
- Stage selectively. **Never `git add -A`.**
- Create a **GitHub backup branch before changing dotfiles.**

becomes a Quickshell config, that script must change — a Quickshell config has no
`msg` equivalent, so it becomes killing and respawning the bar config.

## Constraints

- **Do not reload or restart the user's live session.** Editing
  `config/hypr/hyprland.lua` is fine; `hyprctl reload` is not.
- **Never run throwless Hyprland probes** — they have frozen this machine. Use
  `Hyprland --verify-config` (takes no path argument in 0.56) and `niri validate`.
  Never `pkill qs` or `pkill quickshell` — `quickshell` is a **runtime
  dependency of `dankcalendar-git`**, so killing all instances can break it.
  Kill by config name, never by bare process name.
- **Verify by measurement, not assumption.** When you claim a module works, show
  the command and its real output. "Looks right" has been wrong repeatedly here.
- If a file you touch is generated by `theme-apply`, change the generator or say
  plainly that your change will be overwritten.
- Leave the 11 existing quickshell configs alone. They are the user's own work.

## Definition of done

1. A Quickshell bar config replaces ashell's bar: workspaces, the cat, media
   title + three transport buttons, tray, notification indicator, audio /
   brightness / battery, clock — **all present**.
2. The bar takes colours from `theme-apply`, and a `themesw` switch restarts it
   (documented as a restart, since no reload exists).
3. `Super+Shift+W` still hides and shows the bar, by whatever mechanism the new
   bar supports. Say which.
4. The notification history survives: whoever ends up owning
   `org.freedesktop.Notifications` is stated, mako stays unstarted, and
   `Super+Shift+W`-style bar hiding does not lose notifications.
5. `niri` still works; a keybind change made for the bar does not break niri.
6. ashell is **not removed** until 1–5 are verified. Then remove it and its
   `install.sh` symlink entry in one clearly-labelled commit.
7. Committed, staged selectively, with the commands run and their real output in
   the message.

Report honestly if a piece cannot be done. A shell that runs at 4 cores with
every feature present beats a beautiful one that stutters or drops notifications.
